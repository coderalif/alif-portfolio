# Alif Portfolio

Modern, responsive personal developer portfolio website for **Md Alif Hosen** — Full Stack Developer.

## 🚀 Features
- ⚡ **Lightning Fast:** Built with React 18 & Vite
- 🎨 **Modern Aesthetics:** Styled with Tailwind CSS and Framer Motion animations
- 📱 **Fully Responsive:** Optimized for mobile, tablet, and desktop screens
- 🛠️ **Project Showcase:** Highlights full-stack apps, skills, and experience
- 📬 **Interactive:** Clean navigation, interactive counters, and contact section

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Framer Motion, React Icons
- **Tooling:** Vite, PostCSS, ESLint

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/coderalif/alif-portfolio.git
   ```

2. **Navigate into directory:**
   ```bash
   cd alif-portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
